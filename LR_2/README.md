# LR_2 — Проект: Сайт-портфолио (Vite + Tailwind)

Краткое описание
Проект представляет собой одностраничный сайт-портфолио, собранный с использованием Vite и оформленный с помощью Tailwind CSS. Цель — изучить инструменты сборки современного фронтенда и получить адаптивный, быстрый шаблон для демонстрации работ.

Технологии
- Node.js + npm
- Vite (сборщик/ dev-server)
- Vanilla JavaScript
- Tailwind CSS (CSS-фреймворк)

Структура проекта (ключевые файлы)
- `index.html` — основная страница
- `src/main.js` — точка входа JavaScript
- `src/style.css` — стили (Tailwind)
- `package.json` — зависимости и npm-скрипты

Быстрый старт (локально)
1. Установите зависимости:

```bash
npm install
```

2. Запуск в режиме разработки (hot-reload):

```bash
npm run dev
```

3. Сборка production-версии:

```bash
npm run build
```

4. Локально просмотреть собранную версию:

```bash
npm run preview
```

Что было сделано
- Настроен проект на Vite (шаблон Vanilla JS).
- Интегрирован Tailwind CSS и добавлены базовые утилиты для адаптивного дизайна.
- Реализован основной интерфейс портфолио с секциями для работ, описания и контактной информации.
