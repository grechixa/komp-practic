# Отчёт по лабораторной работе

## Тема: Сборка сайта с помощью Node.js, npm и Vite с использованием CSS-фреймворка.

### Цель работы
Изучить инструменты сборки веб-приложений и создать сайт-портфолио с кастомным дизайном.

### Ход работы
- Установлен и настроен Node.js и npm.
- Создан новый проект с помощью сборщика Vite.
- Выбран шаблон Vanilla JavaScript.
- Разработан сайт-портфолио с использованием CSS-фреймворка Tailwind CSS.
- Выполнен запуск проекта в режиме разработки и проверена корректность работы сайта в браузере.
Результат

Создан одностраничный сайт-портфолио с адаптивным дизайном, собранный с использованием Vite и современного CSS-фреймворка.
