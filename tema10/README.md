# Лабораторная работа №10

## Генерация изображений веб-сервером по запросу

### Описание проекта

Реализовано веб-приложение для генерации изображений по запросу пользователя.

Основной сервер реализован на Flask. Дополнительно выполнено усложнение №1 — создан отдельный маршрут на Django с использованием архитектуры микросервисов.

Flask выполняет роль основного сервера и проксирует запросы к Django-сервису, который генерирует изображения и возвращает готовый JPEG-файл.

## Установка зависимостей

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать:

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

Установить библиотеки:

```bash
pip install flask django pillow requests
```

---

## Запуск проекта

### Запуск Django-сервиса

Перейти в каталог:

```bash
cd django_service
```

Запустить сервер:

```bash
python manage.py runserver 127.0.0.1:8001
```

Сервис будет доступен по адресу:

```text
http://127.0.0.1:8001
```

---

### Запуск Flask-сервера

Открыть второй терминал:

```bash
cd flask_app
```

Запустить:

```bash
python app.py
```

Сервис будет доступен по адресу:

```text
http://127.0.0.1:5000
```


---

### /makeimage_alt

Метод:

```text
GET
```

Параметры:

| Параметр | Описание              |
| -------- | --------------------- |
| width    | ширина изображения    |
| height   | высота изображения    |
| text     | текст для отображения |

Пример:

```text
http://127.0.0.1:8001/makeimage_alt/?width=500&height=300&text=Hello
```

## Реализованное усложнение

### Усложнение №1 — Полиглот

Дополнительный маршрут `/makeimage_alt` реализован на Django как отдельный микросервис.

Flask принимает запросы пользователя и передает их Django-сервису. Django генерирует изображение и возвращает его обратно через Flask.
